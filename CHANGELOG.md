### Added

- API-only Laravel starter kit baseline.
- Sanctum bearer token authentication endpoints.
- Standard API response envelope and JSON-first exception handling.
- `make:api` generator for API controllers, services, requests, resources, tests, DTOs, models, and migrations.
- Composer scripts for CI, code style checks, and test suites.
