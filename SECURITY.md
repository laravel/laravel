# Security Policy

## Supported Versions

Until tagged releases begin, security fixes target the active default branch.

## Reporting a Vulnerability

Please report security issues privately to the project maintainer instead of opening a public issue.

Include:

- A clear description of the vulnerability.
- Steps to reproduce.
- Impact and affected versions or commits, if known.
- Any suggested mitigation.

The maintainer should acknowledge valid reports and coordinate a fix before public disclosure.
